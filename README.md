# Sorting Algorithms in Java

A Java console-based application that demonstrates the implementation of fundamental sorting algorithms through practical problem-solving scenarios. The project focuses on understanding sorting techniques, algorithm efficiency, and their applications using real-world examples.

---

## About the Project

Sorting is one of the fundamental concepts in computer science and plays a vital role in data organization and efficient searching. This project demonstrates the implementation of various sorting algorithms by solving different real-world problems involving arrays.

Each program is implemented independently, allowing learners to understand the working principle, time complexity, and applications of each sorting algorithm.

## Time Complexity

| Algorithm | Best | Average | Worst |
|-----------|------|----------|-------|
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Selection Sort | O(n²) | O(n²) | O(n²) |
| Insertion Sort | O(n) | O(n²) | O(n²) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) |
| Heap Sort | O(n log n) | O(n log n) | O(n log n) |
| Counting Sort | O(n + k) | O(n + k) | O(n + k) |
